## Local setup

```bash
# 1. Create virtual environment
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/macOS

# 2. Install all dependencies
pip install -r scripts/requirements.txt

# 3. Prep your photo (run once; needs the heavy libs)
python scripts/prep_photo.py "path/to/your-photo.jpg"

# 4. Generate ASCII portrait SVG
python scripts/make_ascii_svg.py

# 5. Generate info card SVG
python scripts/make_info_card.py

# 6. Fetch live contributions + render heatmap
python scripts/fetch_contributions.py
python scripts/render_heatmap_svg.py
```

## Deploy to GitHub

```bash
gh repo create Abdellahelb --public --clone
# copy all files into the repo
git add .
git commit -m "feat: animated terminal profile"
git push -u origin main
```

Then go to **Settings → Actions → General → Workflow permissions** and set **Read and write**.
Trigger the workflow once from the Actions tab (`workflow_dispatch`) to verify it commits a fresh SVG.
